# 🌦️ Sun Syncs (SPA)

A sleek and modern Single Page Application (SPA) weather app built using **React + Vite**, **TanStack Query**, **Context API**, **TailwindCSS**, and **daisyUI**.
Get real-time weather information for any city around the globe in an instant!

---

## ✨ Features

- 🔥 Instant weather search by city name
- 🌎 Uses the browser's Geolocation API to get coordinates on page load.
- ⚡ Global weather data (temperature, humidity, weather condition)
- 🌓 Light/Dark mode support
<!-- -  ⚡ Smooth animations with Framer Motion -->
- 🛠️ Powered by Context API for state management
- 📱 Fully responsive and mobile-friendly
- 🎨 Beautiful UI with `TailwindCSS` and `daisyUI`

## 🚀 Installation

### 1. Clone the Repository

```bash
git clone https://github.com/tbs96/weather-app-react.git
cd weather-app
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Get an API Key

- Sign up at [OpenWeatherMap](https://openweathermap.org/api) (or any weather API you prefer).
- Create a `.env` file in the root of the project and add your API key:

```env
VITE_WEATHER_API_KEY=<YOUR_API_KEY>
```

### 4. Start the Development Server

```bash
npm run dev
```

Your app will be running at [http://localhost:5173](http://localhost:5173) 🎉
